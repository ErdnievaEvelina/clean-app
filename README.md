# **CleaningApp Mobile**
* CleaningApp - мобильного приложения для геймификации бытовых задач в совместном жилом пространстве.
* [Backend-сервис](https://github.com/alfoll/cleaning-app-backend)
* Стек: Jetpack Compose, MaterialDesign, Retrofit, MVVM
## Немного о проекте 
**Проблема**: В общих жилых пространствах (квартиры, общежития, дома) постоянно возникают конфликты из-за неравномерного распределения бытовых обязанностей. Напоминания в общих чатах не работают, а чувство несправедливости накапливается.

**Решение**: CleaningApp - это мобильное приложение, которое превращает скучные обязанности в соревновательную игру с внутренней виртуальной валютой (ClutterCoin). Пользователи получают монеты за выполнение задач, а тратят их на реальные привилегии, которые устанавливают сами.
